# 历史上报能带来多少调压收益

一个站点半小时前处于高负荷状态，会改变对它当前状态的判断。这个判断要影响调压，还必须使某个可行的站间 P/Q 分配在当期潮流下更合适。实验分别衡量类别预测、事件发生后选出的档位、监测点电压偏差以及全网越限。

## 时间信息进入控制器的位置

空间控制器根据当前六小时时段和已上报的类别建立条件概率。新增的时间模式还可以读取前一半小时或前一天同一时刻实际收到的上报。训练时，算法按真实半小时时间戳配对，利用历史状态向量估计前后两个时刻的混合分量转移概率，以及每个站点在已知过去类别时的当期类别概率。缺少精确前序时刻的训练记录跳过该配对。

在线将过去的部分量测转换为当期混合权重和各站类别因子，与原空间分布加权。得到的联合概率仍可与同一个 Fourier 电压损失 MPO 缩并。经验电压曲线和交流潮流复核也使用时间信息。在历史中找到至少 32 个符合当前及过去量测的训练时刻时，加入至多 64 条当前空间条件相同的背景记录，使小样本下的评分更平稳。所有方法共用各站资源预算、档位、终端目标和邻站协调协议。

三路对照分别使用当前报告、当前加 30 分钟前报告、当前加 24 小时前报告。回放从空的历史缓冲开始，缺报不会生成历史记录。电压评价在决策完成后，使用真实连续源荷与非线性交流潮流。主实验采用单个历史时刻，分别估计两个时间尺度的价值。接口也支持同时传入两个时刻。

## 预测与实际电压

正的预测改善表示当前报告抵达前，同一表计真实类别的平均负对数似然下降，单位为 nat/表计。电压损失改善取“仅看当前”减“使用历史”，单位为 p.u.。每组比较都使用逐时配对结果。四个首年主工况指两张网各自在正常上报和间歇停报下的常态运行。跨年主工况采用两张网的间歇停报场景，保留首年训练得到的全部参数。

| 实验组 | 历史量测 | 预测改善 | 监测点电压损失改善 | 全网越限率差 |
|---|---|---:|---:|---:|
| 首年四个主工况，115 天 | 30 分钟前 | 0.13649 | 0 | 0 |
| 同上 | 24 小时前 | 0.06938 | −0.00000522 | 0 |
| 次年两个主工况，332 天 | 30 分钟前 | 0.12023 | −0.000000005 | 0 |
| 同上 | 24 小时前 | 0.05793 | −0.00000130 | 0 |

首年 24 小时历史导致的电压损失增加，34 天移动分块的 95% 区间为 [0.00000266, 0.00000749] p.u.。高光伏正常上报的两组补充实验中，两个时间尺度都改善表计类别预测，全网越限率均持平。两张网使用同一户源荷曲线构造节点轨迹，表计的映射位置也相同，因此预测结果的重复不能当作两套独立实测证据。[首年逐工况指标](../examples/temporal.json) · [跨年间歇停报](../examples/external_temporal.json) · [跨年高光伏](../examples/external_temporal_solar.json)

## 两块表交替上报时的调压收益

高光伏工况中令两块表每半小时轮流上报。若本次轮到 A 站，当前控制器只能看到 A 站类别。此时半小时前的报告提供 B 站最近一次实测，前一天同刻的报告则提供 A 站在相同日内时刻的历史状态。三种方法都能调同样的三个 PCC。首年发现这一条件下监测点偏差出现改善后，固定上报规则、参数和站点，在次年独立回放同一实验。

| 使用的报告 | 首年平均监测点损失（p.u.） | 首年相对改善 | 次年平均监测点损失（p.u.） | 次年相对改善 |
|---|---:|---:|---:|---:|
| 仅当前 | 0.00243873 | 基准 | 0.00328035 | 基准 |
| 当前及 30 分钟前 | 0.00240361 | 1.44% | 0.00325536 | 0.76% |
| 当前及 24 小时前 | 0.00238910 | 2.04% | 0.00324369 | 1.12% |

次年两种历史分别使平均监测点损失减少 0.00002499 和 0.00003666 p.u.，34 天分块的 95% 区间分别为 [0.00001951, 0.00003034] 和 [0.00003049, 0.00004186] p.u.。每种方法在两张网各自的监测点损失均有改善。对从未直接上报的十个节点，收到当期报告后的类别负对数似然从 0.70429 降至 0.69446 和 0.69335 nat/节点。

全网越限率须单独解读。首年两张网平均越限率从 2.6721% 变为 2.6902% 和 2.6812%，增量分别来自 69 节点馈线多出的两个和一个半小时时刻。次年从 5.7198% 降至 5.7166%，两种方法的差值区间均包含零。两年回放支持在高光伏、交替上报条件下利用时间信息减小监测点死区外偏差。全网硬越限率尚未显示稳定改善。[首年交替上报结果](../examples/temporal.json) · [次年独立复核](../examples/external_temporal_alternating.json)

为区分日内作息与真实的前后时刻关联，另在高光伏条件下做同钟点对照。替代记录来自首年训练期，与真实历史处在相同半小时位置，两块表同时取自同一替代日期。控制器使用相同的当期上报和动作预算。真实 30 分钟历史相对替代历史使预测损失低 0.1384 nat/表计，真实 24 小时历史低 0.0628 nat/表计。两者监测点电压损失差的 34 天分块区间均包含零。这个对照使用一个固定种子的替代序列，训练和测试季节分布可能不同。[同钟点对照与动作差异](../examples/temporal_placebo.json)

当前模型逐半小时决定一次离散 P/Q。它衡量历史量测对当期电压控制的贡献。储能跨期能量约束、执行器爬坡和多步滚动调度需要另行建模。当前部署入口默认采用通过历史 AC 复核的空间控制，时间模式可按需启用。

## 复现

```bash
python temporal_benchmark.py --output examples/temporal.json
python temporal_placebo.py --output examples/temporal_placebo.json
python external_replay.py --temporal --output examples/external_temporal.json
python external_replay.py --temporal solar_export --output examples/external_temporal_solar.json
python external_replay.py --temporal alternating --output examples/external_temporal_alternating.json
python controller.py --topology case69 --method temporal --clock-bucket 2 --half-hour 29 --observe 12=1 --observe-30m-ago 64=2 --transport process
```
