# 长链馈线的离散协同调压

## 控制问题

IEEE 33 节点系统的 14、18、33 号母线各有一个可调 PCC。各站以 0.025 p.u. 为步长选择有功、无功。共同资源约束为总有功不超过 0.05 p.u.、各站无功绝对值之和不超过 0.05 p.u.。默认监测 18、33 两个末端，电压目标是最小化两点相对 1.0 p.u. 偏离超过 0.02 p.u. 的平均幅度。另行统计全网任意节点超出 [0.95, 1.05] p.u. 的时刻比例。

原控制器从六组总 P/Q 中选一组，18、33 两站平分。新控制器能在同一资源总预算内重新分配档位。正常时有 250 组可行联合动作，33 号站无法提供正向无功时有 190 组。对新算法本身的正确性检验，使用完全相同的可行域、量化步长、概率和控制目标进行集中穷举。

## 每个控制周期的计算

1. **离线物理模型。** 对各站各档位单独做交流潮流，记录各母线电压增量。训练数据来自一户 Ausgrid 实测源荷曲线的时移与缩放。基于训练时段构建 12 站的类别、4 个时段的相关混合概率模型、Fourier 损失算子，以及原六个基准动作的历史全网 AC 电压。各站的可用档位可在决策时按实时无功余量更新。
2. **条件风险。** 观测到部分站点的净有功类别后，得到混合分量的条件权重。在每个分量内逐站乘 Fourier 相位，等价于缩并原来的正弦/余弦 MPO。对终端可能收到的电压增量，按匹配当前观测的训练样本数，将该条件期望和历史死区外偏差加权。TT 先验权重为 32/(32+n)，没有匹配训练样本时使用 TT 先验。
3. **边界筛选。** 利用当前可行的原始基准动作，取出其历史全网 AC 电压。将候选动作相对该基准的电压增量叠加到相同样本中，同时检查 [0.952, 1.048] 和 [0.95, 1.05] 两个范围。只有候选新引入越限时，才需要用消除的越限来补偿，并留出基于配对样本计数的余量。该筛选对应训练样本和增量电压近似，实际效果通过独立时段的非线性潮流统计。
4. **分站选档。** 各站保存本地动作、成本、可用性，以及每个动作的电压增量和预算消耗。前向消息传递可达的累计电压刻度、预算和最低累计成本。本地保留相同边界状态的最佳前驱。最后一站加入条件风险并选出可行状态，再逆向传回前驱，使各站恢复自身动作。三站共需四条邻站消息。该过程对量化目标精确，单个监测点的累计舍入误差界为站数乘电压刻度的一半，此外还有潮流近似误差。

`controller.py` 提供独立的决策入口。应用可调用 `VoltageController.fit(...)` 一次，然后对新观测或本地限额重复调用 `dispatch(...)`。观测采用当前半小时的时段和类别，类别 0、1、2 的界限由训练净有功的三分位点决定。在线选档复用模型与历史参考电压，无需运行交流潮流或枚举联合档位。区域计算可使用本地进程与相邻管道；终端持有条件风险模型和历史参考电压。代码中的多进程实验在同一台机器完成。

## 电气长度与调节余量的配对实验

将 1 到 18 号母线路径上的每段 R 和 X 同倍率放大，保留各支路及其参数。六组实验共用完整的 5,520 个留出半小时时刻、同一训练划分、负荷、光伏和总调节预算。第二种基线允许把 33 号站受限的正向无功全额改派给 18 号站，保留原六个总 P/Q 动作，并为新的分配方式独立重新校准潮流和 Fourier 算子。

| 33 号站正向无功 | 主干电气长度 | 原均分平均损失 | 允许改派的平均损失 | 分布式平均损失 | 全网越限率（原均分 / 改派 / 分布式） |
|---|---:|---:|---:|---:|---|
| 可用 | 1 倍 | 0.000203 | 0.000203 | 0.000201 | 0.00% / 0.00% / 0.00% |
| 可用 | 1.5 倍 | 0.002980 | 0.002980 | 0.002980 | 0.56% / 0.56% / 0.56% |
| 可用 | 2 倍 | 0.008957 | 0.008957 | 0.008840 | 19.55% / 19.55% / 18.79% |
| 受限 | 1 倍 | 0.002548 | 0.000866 | 0.000201 | 0.00% / 0.00% / 0.00% |
| 受限 | 1.5 倍 | 0.013594 | 0.004079 | 0.003046 | 18.91% / 1.83% / 1.79% |
| 受限 | 2 倍 | 0.030013 | 0.009852 | 0.008392 | 52.88% / 21.70% / 21.81% |

在受限工况中，相对原均分方案，每个时刻的平均绝对收益从 0.002347 增至 0.021621 p.u.。两倍与一倍长度的配对收益差为 0.019274 p.u.，按周分块重采样得到的 95% 区间为 [0.019052, 0.019475]。相对允许直接改派的基线，两倍长度下收益为 0.001460 p.u.，区间为 [0.001366, 0.001557]，但全网硬越限率略高。机制可由 AC 灵敏度验证：18 号站无功对本点电压的灵敏度随长度由 0.602 增至 1.314，而 33 号站无功对 18 号电压的灵敏度由 0.098 增至 0.217。各站位置、可用余量及共同约束都影响收益。

原长度下、33 号站余量正常时，平均损失改善的周分块区间包含零。对于 1.5 倍和 2 倍长度，原均分策略的损失已经达到其六个动作在测试集上的事后最优值。此时继续优化这六个动作的选择不能进一步降低平均损失，新增空间来自允许改变站间分工。全部结果包含监测点和中间节点的分项偏差、硬越限率、事后最优及配对区间。该敏感性实验复用同一户时序，不支持直接推广到其他馈线或季节。[完整长度实验结果](../examples/long_feeder.json)

## 计算开销与验证范围

* 六个固定动作、两个监测点、16 阶 Fourier 展开，在 36 种时段与观测组合上，因子化计算与原稠密实现选档完全一致。当前 Windows 测试机上，未缓存的单次评分从 9.80 ms 降至 0.1005 ms；12 个损失算子的数组由 3,155,328 字节降至 113,992 字节。计时包含独立的模型训练、AC 校准与算子构造记录。约 97.5 倍加速只对应六动作评分。[评分精度、时间与存储](../examples/fourier_efficiency.json)
* 分布式控制离线额外保存 7,680 个训练时刻下六个参考动作的 AC 电压（46,080 个工况，可批量计算）。在线开销还包括经验风险、边界筛选、消息编码和选档。三站主实验在八种工况下逐个观测与同目标集中穷举核对，并各抽取一次用独立进程复算。容量受限、不同遥测数量、重负荷及高光伏均有对照。报告包括仅经验评价、仅 Fourier 评价和安全筛选等消融。[八场景结果](../examples/distributed_ieee33.json)
* 另一个固定三档无功预算的规模实验分别使用 3、6、12、18 个调节站。18 站时，988 个可行动作集合归并为 604 个终端边界状态，34 条邻站消息合计 47,349 字节。本机串行模拟分布式流程为 6.71 ms，集中遍历可行子集为 1.19 ms。分布式实现提供区域自治与邻区通信，消息表仍会随监测维数、控制站数和电压精度增长。[站数扩展结果](../examples/dispatch_scaling.json)

## 复现

在仓库根目录安装 `requirements.txt` 后运行：

```bash
python -m unittest discover -v
python realistic_benchmark.py --compare-backends --out results/fourier_efficiency.json
python coordination_benchmark.py --verify-process --out results/distributed_ieee33.json
python long_feeder.py --out results/long_feeder.json
python dispatch_scaling.py --out results/dispatch_scaling.json
python controller.py --clock-bucket 1 --observe 8=1 30=2 --q-limit 33=-0.05,0 --transport process
```
