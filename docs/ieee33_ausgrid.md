# IEEE 33 节点 + Ausgrid 实测源荷实验

## 研究问题与已实现内容

本扩展在具有分支结构的 **Baran–Wu IEEE 33 节点**配电测试系统上验证部分可观测负荷与分布式光伏条件下的概率电压控制。线路阻抗、基础负荷与 32 条常闭支路采用 [MATPOWER `case33bw`](https://github.com/MATPOWER/matpower/blob/master/data/case33bw.m)，标幺基准 10 MVA / 12.66 kV。负荷与 PV 的日内实际变化来自 [Ausgrid Customer 12](https://github.com/pierre-haessig/solarhome-control-bench/tree/master/data) 的 2011–2012 年半小时实测曲线；其余节点注入按 `measured_profiles.py` 明示的规则生成。训练与测试没有时间重叠。

每个样本的 12 个随机源荷节点有三档离散状态，总状态数 **3¹² = 531441**；可观测节点为 **8、30**，其余 10 个节点的类别隐藏。控制设备设置在 **18、33**，按比例共同执行六种有功/无功离散组合；目标为减小这两个末端节点相对 1 p.u. 的超死区电压偏差，目标死区 **±0.02 p.u.**。另外检测全部 33 节点的 0.95–1.05 p.u. 越限情况。

### 计算流程

1. 只用训练期数据计算各节点净功率三档分位数阈值，得到每档的有功/无功代表值。
2. 按 6 小时时段分别训练 3 分量 EM 混合分布，并转化为**非负概率 TT**；同时用相同数据训练独立边缘概率 TT 作对照。
3. 每动作执行 **1+2m** 次完整 AC 潮流，对两个被监控节点同时校准类别到电压的可加近似（m=12，六动作合计 **150 次**）。
4. 对电压死区损失进行余弦 Fourier 分解，生成对角 MPO，不展开 531441 个联合状态；通过条件缩并分别得到各个动作的期望损失。
5. 在未参与训练的连续测试期进行时间均匀抽样，使用**原始连续源荷曲线**为全部动作分别求解非线性交流潮流。比较三种策略：相关概率 TT、条件均值 plug-in、独立概率 TT；另给完整信息动作 oracle 下界。
6. 使用**按天成块自助采样**计算成对收益的 95% 区间，兼顾半小时负荷序列的时间相关性。

### 复现

在仓库根目录执行：

```bash
python -m pip install -r requirements.txt
python -m unittest -v
python realistic_benchmark.py --harmonics 16 --components 3 --max-test 320 \
   --out examples/ieee33_ausgrid_results.json
```

运行 `--solar-scale` 改变光伏渗透率；使用不同 `--seed` 检验 EM 初值与数据分布拟合的稳定性。可直接运行 `python sensitivity.py` 完成三个 PV 缩放系数 × 三个 EM 随机种子的稳健性扫描，并生成 `examples/ieee33_ausgrid_sensitivity.csv`。实验自动记录开关动作差异、期望损失、独立 AC 验证、越限频率、拟合误差、日块 bootstrap 置信区间及离线 AC 调用数。

### 方法适用范围

`feeder33.py` 使用**完整径向 AC 电流前推回代**，对实际验证样本和 33 节点均求解交流潮流；MPO 对应**在训练数据分类代表点附近，经 AC 校准的可加电压替代模型**。这区分了物理系统验证与在线近似风险决策的计算角色。负荷数据本身只来自一户的实测历史，通过时移和缩放映射到多节点，所以节点间的相关性属于**构造场景的统计结构**。报告的性能结果需要结合真实数据来源、情景映射、测试时段和 bootstrap 区间解释。

**更进一步**：替换为多户同步测量源荷、配网实测时空数据与 IEEE 69/123 节点馈线；引入动态概率漂移、全网风险 MPO 与独立场景优化基线。
