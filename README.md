# MPS–MPO 低秩概率电压控制：可复现实验原型（v2）

> **定位：研究代码，不是现场控制软件。** 原始 10 母线实验使用完整非线性交流潮流计算状态—动作损失；高维实验使用少量交流潮流校准得到的**仿射电压替代模型**构造 MPO。后者的低秩与傅里叶近似误差界**不构成真实交流潮流安全性保证**。

## 一、相对原始代码改进了什么？

1. **原生三档物理维度。** `tensor.py` 的每个负荷变量对应一个维度为 3 的站点，不再把 `0/1/2` 编为两位二进制并引入非法 `11` 状态。原始 10 母线实验仍保留：观测节点 6/9，缺测节点 3，六个有功无功动作。
2. **可调张量键维和截断误差。** TT-SVD 支持 `max_bond`、相对 Frobenius 截断阈值；截断后的 Born-MPS 自动重新归一化。输出 `decision_diagnostics.csv`，逐情境记录动作评分误差、实际决策后悔值和动作间隔；**安全指示张量始终精确分解，不参与截断**。但截断概率模型下，安全概率仍是估计值。
3. **非枚举的高维损失 MPO。** `scalable.py` 只执行 `6(2m+1)` 次离线交流潮流调用，计算每个动作在一个参考运行点的末端电压与各负荷灵敏度，得到 `δV_a(x)=c_a+Σ_i f_{a,i}(x_i)`。对原项目的电压死区损失 `max(0,|δV|-d)` 做截断余弦傅里叶展开，解析构造键维至多 `2K+1` 的对角 MPO；整个构造**不生成 `3^m` 个状态的损失数组**。
4. **可从有限样本学习高维概率。** `probability_tt.py` 使用正常通信时的完整负荷样本，EM 估计非负有限混合概率 `p(x)=Σ_k w_k ∏_i p_{ki}(x_i)`，解析表示为键维不超过混合分量数的概率 TT（经典 MPS），随后在线条件缩并。这不同于原始平方根/Born-MPS 的双层缩并；两种机制在 `benchmark.py` 中可分别测试。
5. **多缺测负荷、独立交流潮流对照。** 增加 `4/6/10/16` 个随机负荷（其中 2 个可观测，其他缺测）的合成径向馈线，并检查 Fourier 表示误差、离线交流潮流调用次数、存储规模、真实交流潮流样本下的控制损失、条件均值基线与成对差异区间。
6. **14 项回归与数值测试。** 原始已知分布动作切换、精确缩并、保存模型重载；加上可调键维、概率归一化、条件投影、非枚举 Fourier MPO、EM 学习概率 TT、交流潮流校准等。测试不依赖大型数据文件。

## 二、数学定义：两种概率 MPS 不应混淆

**原始小规模实验：Born-MPS。** 令 `ψ(x)=sqrt(p(x))`，则

\[
J_a(y)=\frac{\langle\psi|P_y O_a P_y|\psi\rangle}{\langle\psi|P_y|\psi\rangle},
\quad O_a=\mathrm{diag}(L_a(x)).
\]

该式是精确条件期望；如果限制键维，`ψ` 表示的是**另一个经归一化的近似概率分布**，因此不能把 MPO 截断误差和概率估计误差混为一谈。

**高维可学习实验：概率 TT。** EM 训练一个非负的低秩混合分布，其概率张量直接写作 TT：

\[
p(x_1,\ldots,x_m)=\sum_{k=1}^{K}w_k\prod_{i=1}^{m}p_{ki}(x_i),\qquad
J_a(y)=\frac{\sum_x p(x){\bf1}_{Y=y}L_a(x)}{\sum_x p(x){\bf1}_{Y=y}}.
\]

这里直接使用 `probability_scores` 的**单层** TT 缩并；没有将 `p` 当作 Born 幅度再平方。生成已知低秩 Born 概率的模式仅用于核对控制算法与检验计算复杂度，并不代表样本学习结果。

**高维 MPO。** 对校准的仿射电压偏差 `δV_a=c_a+Σ_i f_{ai}(x_i)`，在所有可能负荷/动作范围内选择共同的 `[-D,D]`，以 `K` 项余弦 Fourier 级数近似 `max(0,|δV|-d)`。利用三角函数加法公式，可以直接构造实数 TT，每个中间键维为 `2K+1`。在输入 `|δV|≤D` 的范围内，具有保守的一致误差界：

\[
\|L_{\mathrm{affine}}-L_{\mathrm{Fourier}}\|_\infty
\le \frac{4D}{\pi^2 K}.
\]

如果所有可行动作的真实条件评分估计误差均不超过 `ε`，近似选出的动作对**该精确评分体系**的后悔值不超过 `2ε`；动作最优/次优分数间隔超过 `2ε` 时排序保持不变。**这里的 ε 只覆盖相应近似，不能自动覆盖非线性 AC 模型失配与概率 EM 的统计误差。**

## 三、复现实验

```bash
python -m pip install -r requirements.txt
python -m unittest -v

# 原始 10 母线场景：保留 AC 潮流、训练/测试分离和确切枚举对照。
python run.py --out results/baseline
python run.py --out results/baseline --decide B 20261120 0.05 0.10

# 键维截断：将输出单独保存，避免覆盖精确基线。
python run.py --out results/rank2 --max-bond 2

# 高维已知 Born 概率，AC 校准的仿射算子；仅小规模核对完整枚举。
python benchmark.py --sites 4 6 10 16 --harmonics 16 \
    --samples 10000 --ac-check 400 --out results/scaling_known.csv

# 高维从 6000 条正常通信样本训练概率 TT（EM 三分量）。
python benchmark.py --sites 4 6 10 16 --harmonics 16 \
    --probability-source em-learned --train-samples 6000 \
    --components 3 --samples 10000 --ac-check 400 \
    --out results/scaling_learned.csv

# 物理对照：不做 AC 灵敏度校准，改用一阶径向潮流灵敏度。
python benchmark.py --sites 4 6 10 16 --surrogate lin-distflow \
    --out results/scaling_lindistflow.csv
```

Python 3.10+，NumPy 1.24+。种子固定，生成概率模型及所有负荷样本为**合成数据**；未使用真实配电网数据。`benchmark.py` 的计时随机器而异，不能当作跨设备的性能排名。首次使用旧版 `model.npz` 请重新执行 `run.py`，新版 `format_version=2` 的张量具有三个物理站点而非六个二进制站点。

### 实测检查（固定参数，单次可复现实验）

| 随机负荷数 m | 状态总数 3^m | 单动作 Fourier MPO 标量数 | 离线 AC 校准调用数（六动作） | 概率模式 |
|---:|---:|---:|---:|---|
| 4 | 81 | 6,732 | 54 | 已知 Born / EM 可选 |
| 6 | 729 | 13,266 | 78 | 同上 |
| 10 | 59,049 | 26,334 | 126 | 同上 |
| 16 | 43,046,721 | 45,936 | 198 | 同上 |

这些数字的意义是：当变量数增加到 10 或 16 时，**构造和存储仿射损失近似算子**的代价不再与 `3^m` 成正比。它**不意味着完整非线性交流潮流损失 MPO 获得同样的误差保证**；也不代表在 `m=4/6` 时有压缩优势（彼时 MPO 反而比直接表大）。

对使用 **AC 校准、已知分布** 的合成场景，在另取的 400 个条件样本上以非线性 AC 潮流评估：`m=10` 时相对条件均值动作的平均损失降低约 `4.74e-4 p.u.`，成对正态近似的 95% 区间约 `[2.18e-4, 7.30e-4]`；`m=16` 时单次平均降低约 `2.67e-4 p.u.`，区间跨零。因此**不能宣称跨规模稳定显著获益**。使用训练得到的 EM 模型时统计误差可能进一步改变动作，详细数据见 `examples/` 两个 CSV。这里的性能验证是仿真样本结果，不是物理安全性证明。

### 物理、安全和统计限制

- **基础 10 节点：** `powerflow.py` 对 27×6 种状态—动作组合计算精确交流潮流及所有母线电压，安全指示符为精确 TT；训练仅 100 条/工况，基线样本外未表现出相对条件均值的稳定收益。
- **高维实验：** `scalable.py` 中的馈线是可复现的、线路阻抗随规模缩放的**合成径向链**，不是 IEEE 标准系统。AC 仅用于离线局部灵敏度校准与独立验证，MPO 操作的是仿射电压替代模型。该部分**尚未实现满足真实 AC 硬电压约束的可认证控制**，请勿将输出用于电网设备。`ac_unsafe_fraction` 仅指验证样本中的越限比例。
- **概率学习：** EM 模型来自完整观测的合成训练样本；未知机制是否符合有限混合假设、局部最优、分布漂移和未观测状态都可能导致误差。已知 Born 分布只用来提供已知真值对照。
- **Fourier：** 一致误差界只针对包住**所有可能仿射电压偏差**的区间，不约束真实 AC 误差；若选择更低的 Fourier 阶数，应重新验证评分误差与动作差距。
- **下一步：** 将条件概率学习、可认证电压范围以及非枚举 AC 残差修正联合研究；与直接场景采样、鲁棒/机会约束最优化、独立概率模型和条件均值法做系统对照。

|---|---|
| `powerflow.py` | 原始十节点非线性交流潮流、动作与损失 |

| `config.json`, `requirements.txt` | 原始物理参数与依赖 |
