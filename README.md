# MPS–MPO Control

### 面向部分可观测配电网的低秩概率电压控制
**Low-Rank Probabilistic Voltage Control for Partially Observed Distribution Networks**

本项目提出并实现了一套将 **相关源荷概率建模（MPS/TT）—物理驱动损失表示（MPO）—条件期望最小化控制** 连接起来的研究流程。核心目标是在大量负荷不可观测时，利用有限的实时测量与历史源荷规律，实现高维不确定性下的电压控制决策。

> **成果概览：** 在 **IEEE 33 节点标准配电网 + Ausgrid 实测源荷时序驱动** 的主实验中，相对条件均值法，平均电压损失降低 **53.8%**；相对独立概率 TT 降低 **19.3%**。高维规模实验已处理 **43,046,721** 个潜在联合状态，16 变量单动作低秩 MPO 较完整损失表减少约 **937 倍**存储。

### 主实验：不同控制策略的电压损失

在 320 个未参与训练的时刻上，使用**连续源荷注入 + 非线性 AC 潮流**评价，数值越小越好。

| 控制方法 | 平均电压损失 (p.u.) | 相比条件均值法 |
|---|---:|---:|
| 条件均值 plug-in | 0.000392832 | 基线 |
| 独立概率 TT | 0.000224815 | 降低 42.8% |
| **相关概率 TT–MPO** | **0.000181419** | **降低 53.8%** |

相关概率 TT–MPO 相对条件均值法的平均损失差为 **2.114 × 10⁻⁴ p.u.**，按天分块 bootstrap 的 95% 区间为 **[1.206 × 10⁻⁴, 3.118 × 10⁻⁴] p.u.**；相对独立概率 TT 的平均损失差为 **4.340 × 10⁻⁵ p.u.**。该实验选出的动作在 **57.5%** 的测试时刻与条件均值法不同。

## 2. 技术路线 | How It Works

```text
历史源荷时间序列 ─→ EM 学习相关联合概率 ─→ 非负概率 MPS/TT ─┐
                                                                ├─→ 观测条件下的张量缩并
IEEE 33 节点 + AC 潮流 ─→ 电压灵敏度校准 ─→ Fourier 损失 MPO ─┘         │
                                                                          ↓
                                                           评价六种 P/Q 动作
                                                                          ↓
                                                            选择期望损失最小的动作
                                                                          ↓
                                                      留出时序 + 全网非线性 AC 验证
```

**概率层（MPS / TT）**：从历史完整观测样本学习多节点联合概率，保留节点间统计相关性。对于有限混合模型

$$
p(x_1,\ldots,x_m)=\sum_{k=1}^{C}w_k\prod_{i=1}^{m}p_{ki}(x_i),
$$

可解析构建键维不超过 `C` 的**非负概率 TT**；每个三档变量只占一个物理站点。项目还保留平方根概率幅度的 **Born-MPS** 实现，用于精确缩并、截断研究和已知分布对照，两种概率表示在实现中分别处理。

**物理层（MPO）**：对每个动作在参考状态附近执行少量非线性交流潮流，通过有限差分得到监控节点电压的可加仿射近似

$$
\Delta V_a(x)\approx c_a+\sum_{i=1}^{m} f_{a,i}(x_i).
$$

对电压死区损失 `L_a(x)=\max(0,|\Delta V_a(x)|-d)` 进行余弦 Fourier 展开，并使用三角函数加法公式**直接生成对角 MPO**。采用 `K` 个谐波时，MPO 最大键维为 `2K+1`，无需预先建立指数规模的完整损失表。

**决策层（条件期望）**：只知道部分观测 `y` 时，通过条件缩并评估

$$
J_a(y)=\mathbb E[L_a(X)\mid Y=y],\qquad
a^*(y)=\arg\min_{a\in\mathcal A} J_a(y).
$$

该流程用联合概率信息替代单点负荷预测来评价动作，同时具备键维限制、张量截断和决策误差诊断功能。

## 3. 标准配网与实测源荷验证

- **网络：** MATPOWER `case33bw`，Baran–Wu IEEE 33 节点分支型径向测试馈线；全网 AC 前推回代，监控母线 **18、33**。
- **源荷时序：** Ausgrid 匿名住宅 Customer 12，**2011-07 至 2012-06 的 17,568 条半小时用电 GC / 光伏 GG 实测记录**。
- **不完全观测：** 将实测时序按明示的日期时移、容量缩放构造为 **12 个源荷节点**的场景，**2 个可观测、10 个隐藏**，离散状态空间 **531,441**。
- **低秩构造：** 三分量 EM 概率 TT 的示例存储为 **288 个标量**；单动作、单监控点的 Fourier MPO 使用 **32,868 个标量**（最大键维 **33**）。
- **交流潮流校准：** 六种有功/无功动作，合计 **150 次离线 AC 潮流计算**，同时校准两个监控点。
- **独立评价：** 按原始测量时间切分训练/测试；测试时以**连续实际幅值映射的节点注入**为输入，使用完整 AC 潮流评价全部动作，采用按天分块的 bootstrap 区间。

**数据结构说明：** 网络使用公开的 IEEE 33 节点标准参数；时间变化来自**一户实测源荷曲线**；12 个节点的功率是经过时移与缩放形成的实验注入，因此属于“标准馈线 + 实测时序驱动的多节点场景”，不是 12 户同步实测的馈线数据。高维 MPO 由 **AC 校准的仿射电压模型** 构建，控制效果再用完整非线性 AC 潮流验证。

## 4. 高维计算规模与存储优势

下表来自另一组可重复的**合成高维径向馈线**规模实验，控制动作数为 6，Fourier 谐波数为 16：

| 随机负荷变量 `m` | 完整状态 `3^m` | 单动作 Fourier MPO 标量数 | 离线 AC 校准次数 |
|---:|---:|---:|---:|
| 4 | 81 | 6,732 | 54 |
| 6 | 729 | 13,266 | 78 |
| 10 | 59,049 | 26,334 | 126 |
| **16** | **43,046,721** | **45,936** | **198** |

MPO 构造成本随变量数增长，而完整状态表指数增长。在 16 变量配置下，45,936 个标量替代 43,046,721 个状态损失值，存储减少约 **937 倍**。这一收益针对**AC 校准仿射损失 MPO 的表示**；数值精度还由仿射模型及 Fourier 展开阶数共同决定。

此外，当前实现包含 Fourier 逼近的一致误差界：

$$
\|L_{\mathrm{affine}}-\widetilde L_{\mathrm{MPO}}\|_\infty
\le \frac{4D}{\pi^2K},
$$

以及条件评分误差不超过 `\varepsilon` 时的动作后悔值界：

$$
J_{\widetilde a}(y)-J_{a^*}(y)\le2\varepsilon.
$$

它们为控制精度与张量秩的协同选取提供量化依据。

## 5. 快速复现 | Reproduce

需要 Python 3.10+ 与 NumPy 1.24+。仓库已提供可追溯数据、固定随机种子、测试和结果文件。

```bash
python -m pip install -r requirements.txt
python -m unittest discover -v

# 主要成果：IEEE 33 节点 + Ausgrid 实测源荷
python realistic_benchmark.py --harmonics 16 --components 3 --max-test 320 \
    --out examples/ieee33_ausgrid_results.json

# 光伏渗透率 × EM 随机种子敏感性
python sensitivity.py

# 原始 10 节点交流潮流验证
python run.py --out results/baseline

# 截断键维与决策误差
python run.py --out results/rank2 --max-bond 2

# 16 变量以内的合成高维规模实验
python benchmark.py --sites 4 6 10 16 --harmonics 16 \
    --samples 10000 --ac-check 400 --out results/scaling_known.csv

# 高维样本学习概率模式
python benchmark.py --sites 4 6 10 16 --harmonics 16 \
    --probability-source em-learned --train-samples 6000 \
    --components 3 --samples 10000 --ac-check 400 \
    --out results/scaling_learned.csv
```

## 7. 研究方向

已实现的关键链条是 **实测源荷驱动 → 相关概率 TT 学习 → 物理损失 MPO 构造 → 部分观测条件决策 → 独立 AC 评价**。后续重点研究多户同步源荷测量、标准馈线跨工况迁移、低秩非线性 AC 残差修正，以及面向安全约束的条件越限概率与风险控制。
